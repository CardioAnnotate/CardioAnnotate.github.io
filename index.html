CardioAnnotate — Changelog

PRE-RELEASE v0.3.0 — PSD visualization and report generation

  • New Report generation Include the ability to generate and print reports of the analysis.
  • New PSD plot window (Statistics → Signal quality): shows the Welch power spectral density of the visible ECG segment for the active channel, with the SQI subbands shaded on the curve — baseline (0–1 Hz), QRS band (5–15 Hz), the 5–40 Hz pSQI/basSQI window, and the mains ± width band — alongside a live pSQI / kSQI / basSQI / lineSQI readout.
  • New HRV PSD plot window (Statistics → HRV): shows the RR-interval power spectrum (4 Hz-interpolated periodogram) with the ULF / VLF / LF / HF bands shaded and a live band-power readout, plus a linear/log frequency-axis toggle (default linear, matching standard HRV convention).
  • New RR interval plot window (Statistics → HRV): shows the RR-interval tachogram for the visible segment, with a time/beat-number x-axis toggle and a "show flagged intervals" toggle that bridges flagged/excluded intervals onto the curve with a dashed segment instead of leaving them disconnected.
  • Internal: computeSQIForVisibleSegment and computeHRVForVisibleSegment now additionally expose their underlying frequency/PSD arrays so both plots can reuse the spectra already computed for the SQI ratios and ULF/VLF/LF/HF band powers, instead of recomputing them. No change to any existing SQI or HRV numeric output.

PRE-RELEASE v0.2.0 — RR review & annotation-consistent correction

  • The combined RR outlier / GP-imputation / auto-insert / auto-delete routine has been split into four explicit stages: Detection → structural suggestion → preview → apply. No R-peak is ever added, deleted or moved without a deliberate user action.
  • Every suspicious region now becomes a persistent review case that distinguishes an ordinary RR timing artifact, a missed R peak, a false-positive R peak, a misplaced R peak, and a true physiological interval.
  • New per-case review panel with Correct timing with GP, Add missing R peak(s), Delete false-positive R peak, Move misplaced R peak and Retain as physiological, plus optional QRS snapping, preview, and an HRV-inclusion switch that is independent of the physiological decision.
  • New structural classifiers for false-positive and misplaced R peaks, with configurable thresholds (α, β, γ, gap ratio, local-median window) exposed in the UI.
  • Corrected RR is now geometrically consistent with the displayed R-peak positions: GP predicts intervals jointly inside fixed bounding peaks and the predictions are conditioned on the observed bounding duration, then peaks are repositioned and RR is re-derived from the annotations.
  • Missing-beat reconstruction no longer inserts equally spaced peaks: the local median only proposes a beat count, candidate counts are ranked, and positions come from the sum-constrained GP posterior.
  • Flagged markers redesigned. The original R-peak fill is retained and status is shown as a hollow ring plus a colored interval segment (amber / blue / cyan / orange / magenta / green), with full hover detail.
  • Complete undo for all structural repairs, and cached RR corrections are invalidated on peak add/delete/move, re-detection, channel change, segment change and import.
  • HRV fix: excluded intervals keep their sequence position as missing values, so RMSSD, NN50, pNN50 and the Poincaré descriptors only use originally adjacent pairs.
  • GP defaults preserved: kernels, hyper-parameter values and RR-in-seconds convention are unchanged. GP now also reports posterior uncertainty, and is centred on the training mean (documented fix for a zero-mean posterior collapse).
  • New RR-correction metadata in the details view, in CSV export and in saved sessions.
  • Add support for unit time coordinate on the x-axis.
  • Updated PSD formulation.
